# Nature 与 Science 选读

## 定位与选题

每日学习中的两个独立顶部Tab，正刊每天各目标3篇、上限3篇，每天北京时间08:00更新，围绕**健康、生活、统计、反直觉发现**。它们不继承美股研究的半导体→电力→AI优先级，不主推技术机制、模型或芯片性能，不强行解释股价。

- 健康：睡眠、运动、饮食、习惯、压力与身心健康；优先与普通成年人有关的人体研究。
- 生活：幸福感、人际关系、消费、时间分配、工作和居住环境。
- 统计：相关和因果、选择偏差、幸存者偏差、基准率、绝对与相对风险、复现。可做选题，也是每篇的证据检查。
- 反直觉：研究能纠正常识误解时再强调；不设猎奇配额，不把单篇异常结果当作推翻共识。

普通成年人无需专业背景也能读懂。首选有明确问题、可解释证据和日常启发的论文；不把实验方法细节堆成科普。单篇正文以约200～400个中文字为目标，不含原题、作者、来源和阅读范围说明；证据边界不能为凑字数删掉。

## 来源与权限

这是用户新增论文栏目授权的**非X论文来源例外**，只用于本栏目，不放宽新闻的Grok两路径限制。

1. 使用Grok发现候选时优先Bot、网页备用，再回正刊核对；Grok不可用记录原因，允许直接查期刊、Crossref、PubMed及作者/机构合法公开版本。不能冒称取得了Grok结果，不绕过付费或登录限制。
2. 只以Nature和Science正刊研究为主条目。Nature Communications、Nature Medicine、Science Advances、研究亮点和新闻不能冒充两本正刊论文；其他期刊可作为复现、反证或更正的辅助证据，明确标注。
3. DOI、原题、作者、首次正式发表日期和规范期刊链接交叉核对。原始发表日期与北京时间选读日期分别保存。优先近30天；无适合新作时可选有价值的往期论文，显式标为「往期精选」，不能伪装当日新发表。
4. 查询更正、撤稿及相关复现；争议会改变主结论时必须进入正文。没有完成影响判断的重大更正/撤稿疑点不能发布。不能声称一次检索覆盖了全部文献。
5. 阅读范围准确标为正文、正文节选或摘要。摘要速读只能陈述公开摘要与已核对来源支持的事实，不能假装读过方法和补充材料。
6. 新人名按项目登记表处理；可以仅列第一作者并标「等」，不把不完整名单当成完整作者表。

## 每篇的逻辑闭环

前台仅四部分：**结论 → 实验过程 → 实验结果 → 结论边界**，全部展开。明确回答支持什么，再写对象/样本、分组/对照、干预或比较、测量及效应。观察/自然实验不伪装随机实验，未取得方法证据不补造流程；不制造不受证据支持的确定性。

内部仍保存problem、method、findings、statistics、limitations、meaning六项和accessNote/accessLevel供核验，不逐项铺UI。实质复现/更正直接进入结论或边界，不把阅读/检索经过当正文。

## 日常执行与保留

配置真源为config/learning.json的journalPolicy；每天08:00两刊各目标3篇，不新增任务，不要求新闻先成功，20:00不重复更新。

每刊独立：先查DOI及日期，写范围和查询清单，再检索核验。满3篇跳过，未满可补余下名额；无合格内容留空，不用子刊或重复论文充数。

本轮载荷存`data/paper-reviews/`，包含`reviews`和两刊`coverage`。覆盖状态区分完成、部分和失败，保存实际查询、核对时间与原因。运行：

```sh
npm run learning:publish-papers -- data/paper-reviews/<本轮载荷>.json
```

发布器按契约核对并合并到`data/journal-learning.json`；不覆写已有ID或DOI，同刊同日最多3篇。失败保留旧内容；两刊独立，不清空知识或另一刊。更正需保留原证据并明确人工修订依据，不能删除旧卡以假装重新收录。

默认最近有内容的一日，多日期才显示精简日期选择器，保留往期。发表日与往期身份可见；阅读范围、更正核对经过、覆盖说明和DOI保留在数据/审计，不铺UI。构建不发布操作载荷。

结构字段见发布器及`scripts/lib/journal-learning.js`：原题、DOI、日期、作者简介、类别、研究阶段、摘要六段、阅读范围与来源为必填。`selectionKind: classic`表示超过近期窗口的往期精选，不代表已证明是经典或共识。
