# 每日学习

侧边栏「每日学习」包含四个顶部Tab：每日趣事、基础知识讲解、Nature、Science。前两项连接美股当日发现与长期知识；两刊独立偏健康、生活、统计与反直觉，不沿用技术主线。均不降低证据门槛。

## 内容来源与频率

- 本机工作日20:30、周末唯一08:00总编排中的独立学习批次执行，不新增任务频率。
- 每日趣事只从当天已经完成采集、达到项目门槛并保留真实X原帖的事件中二次筛选；基础知识结合项目知识库解释概念，二者不额外搜索。两刊按[论文SOP](JOURNAL_PAPERS.md)独立检索，允许其明确限定的非X原始论文来源。
- 当天最后一个成功批次可发布一次，每日趣事最多3条、基础知识每天最多新增1个；没有合格内容可以是0条，禁止凑数。
- 两刊每日各目标1篇，优先近期，允许清晰标注往期精选；没有合格内容留空。已选DOI不重复，旧选读按日期保留。
- 网页不提供手动更新入口；本机Codex学习批次负责生成，单项失败保留旧内容并独立记录，不阻塞另一刊或原学习内容。

## 每日趣事

每日趣事不是名人八卦、段子或普通新闻摘要。入选内容必须同时满足：

1. 有真实、可回查的 X 原帖和准确时间；
2. 相对当天其他信息具有反直觉、机制启发或产业观察价值；
3. 能连接半导体、电力、AI落地或相关财务机制；
4. 标题、摘要与“为什么有意思”不重复主新闻卡片的写法；
5. 可以关联一个基础知识点，但不强制每天新建知识点。

字段：`id`、`date`（北京时间日期）、`category`、`title`、`summary`、`whyInteresting`、可选 `knowledgePointId`，以及 `source.author/url/publishedAt`。

## 基础知识讲解

一个知识点只保存为一个对象，内部强制同时存在两份表达，避免专业版和故事版演变成两套结论。

### 专业版

- `definition`：准确下定义，必要术语首次出现时解释；
- `mechanism`：说明输入、过程、约束和结果；
- `whyItMatters`：连接收入、成本、资本开支、供需、竞争格局或估值；
- `signals`：列出可观察、可核验的指标，不写空泛判断。

### 故事版

- 目标读者是18岁以上、没有行业背景的普通成年人，不写儿童口吻；
- 用一个完整生活或工作场景讲清同一条因果链，人物、数字和引语不得伪装成真实事件；
- `mapping` 明确故事角色分别对应哪个专业概念；
- `boundary` 明确类比在哪些地方会失真，故事不能替代专业定义；
- 不得加入专业版没有的事实、预测或投资结论。

共同字段：`id`、`title`、`category`、`updatedAt`、`professional`、`story`、`commonMistakes`、`relatedCuriosityIds`、`sources`。来源仍须符合本项目X证据规则。

## 页面行为

- 四个顶部Tab支持键盘方向键、Home、End；URL使用`?tab=curiosities`、`basics`、`nature`或`science`。
- 基础知识卡同时展示专业版和故事版；桌面双栏、手机单栏，所有正文完整显示。
- 没有内容时显示真实空态，不生成示例新闻或占位知识。
- 论文卡按研究问题、方法、发现、统计提醒、局限、生活启发展开；日期可回看往期，发表与选读时间分开，阅读范围明确。规则与唯一维护入口见[JOURNAL_PAPERS](JOURNAL_PAPERS.md)。
