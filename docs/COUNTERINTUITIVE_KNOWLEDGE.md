# 反直觉小知识

「每日学习」的独立顶部Tab，`?tab=counterintuitive`。每天目标5条、上限5条；沿用既有“没有高价值不凑数”原则，缺额如实说明。偏健康、生活、统计和行为认知，不继承美股技术优先级，也不是把「每日趣事」新闻改写一次。

## 选题与表达

- 纠正一个具体、常见且值得纠正的直觉，不做冷笑话、猎奇、名人八卦或未经验证的“惊人事实”。
- 优先不同生活问题，不把同一研究拆成五条，避免每天反复推相同知识点；跨期按稳定`knowledgeKey`去重，换标题也不能重发。
- 每条约100～180个中文字，四段默认展开：**常见直觉 → 证据怎么说 → 为什么 → 适用边界**。标题不把条件性结论变成绝对结论。
- 相关与因果、人体与动物、短期与长期、样本与目标人群、相对与绝对风险须按实际证据区分；解释中的机制推断明确标注，不补造确定性因果。
- 不给个人诊断、处方、停药或增加风险的建议，不为凑数制造焦虑。18岁以上普通成年人无需专业背景即可读懂。

## 证据与来源

优先复用已核验论文与项目材料，无须每条重新宽搜。需要新增外部信息时先用Grok发现，再核对原始论文、作者/机构公开版本、官方统计或教育资料；Grok不可用记录原因，只允许上述限定的非X科普来源补足。它们仅服务这个知识栏目，不扩大X新闻第三路径，不直访X补采，不用模型记忆或内容农场代替来源。

每条保存可回查链接、发布机构、原始日期（未查到明确说明）、实际核对时间和摘要/节选/正文阅读范围；查相关更正与反证。健康结论有实质争议时要在边界说明；证据无法支持反直觉主张就不入选。人名原文和简介遵守项目登记表，没有提到人时`people: []`。

## 每日运营

每天北京时间20:00和每日学习一起执行，不新增任务，也不在其他新闻更新中重复推五条。先读配置、历史知识点与当天组：

1. 先写候选问题、计划来源和查询清单，再检索；复用证据也写明来源，不伪称当日新研究。
2. 筛出最多5个独立知识点，检查每条四段和证据。当天已有5条则跳过，少于5条可只补余下名额；失败保留已验收条目和往期。
3. 本轮载荷保存到`data/counterintuitive-runs/`，含`date`、新增`items`、`coverage`。`coverage`写`status: complete|partial|failed`、原因`note`、实际`queries`及`checkedAt`；满5条才可标完成，少于5条标部分，无条目且请求失败才标失败。
4. `npm run learning:publish-counterintuitive -- <载荷.json>`只按契约合并数据，不采集、不推Git、不部署。已有卡片不覆盖，重复知识点报错，补齐必须保留本日已验收条目。更正单独保留原证据和依据，不删卡冒充新知识。
5. 与当次其他批次统一提交、推送及核验。前台只展示发布数据，后台载荷和审计不进入构建。

## 数据与页面

- 配置：`config/learning.json`的`counterintuitivePolicy`。
- 展示数据：`data/counterintuitive-learning.json`，初始`updatedAt: null, editions: []`，没有编造的内容或更新时间。
- 每组：北京时间`date`、`items`、`coverage`。每条：`id`、稳定英文`knowledgeKey`、`topic`、`title`、`intuition`、`fact`、`explanation`、`boundary`、`people`及`sources`。
- `sources`每项为`label`、`publisher`、HTTPS `url`、`publishedDate`、`accessLevel`、`checkedAt`；日期未知时`publishedDate: null`并提供`dateNote`。
- 默认最近有内容的一组，按日期回看往期；失败提示本轮缺口，不清空旧内容。数据加载失败不影响其他顶部Tab。全部正文展开、不截断。
