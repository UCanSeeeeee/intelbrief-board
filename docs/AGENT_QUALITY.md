# 任务理解、验证与交接

本文件是共享方法的公开项目子集。来源与校验见同目录的 `AGENT_QUALITY.source.json`。它补充工作方法；本仓库 AGENTS、产品契约、来源路径与发布约定决定实际权限和顺序。

- 先核对本次结果、具体页面／Tab、已有授权与完成标准。状态和诊断先只读；实现请求在已有授权内完成。先复述的请求只复述；后续补充沿当前任务处理。
- 只读取相关入口，按路径和归属核对同名对象。缺少会改变权限或不可逆结果的信息才提出具体问题，普通可逆选择自行处理并推进。
- 维护当前有效状态，区分用户决定、助手候选、事实和推断；补录旧事件不成为当前状态。停用方案不因额度恢复自动复活。
- 交接保存当前目标、有效约束、实际进度、证据入口、剩余动作及阻塞。引用已有原始记录，当前正文合并过期叙述，不复制聊天或累积修改流水账。
- 故障先复现或收集能区分假设的证据，沿输入到展示定位，最小变动检验原因。性能先测瓶颈；只有得到授权才停服务或增加运行服务。
- 验证依本仓库约定执行，采用夹具，不改真实新闻。浏览器交互、构建、采集、提交、推送和生产部署各需对应证据；未做的验证明确保留未知，不把代码修改说成上线。
- 内容保留原始作者、链接、事件／发布时间与覆盖缺口。失败不等于无新增；Grok转述不等于已直读原帖。不得借本方法改动采集路径、同帖跨板块规则或内容运营归属。
- 首句直接回答结果，给必要依据和影响，删除重复请求、空泛铺垫和过量格式。短问短答，不强行建计划、课程、测试或报告。

本文件不依赖宿主目录，不授权访问其他仓库、私有资料、账户、后台服务或委派代理；项目规则变化只能在本项目按授权维护。
