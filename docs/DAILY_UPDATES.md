# 每日更新

`daily.html` / `daily.js`是只读聚合页，侧边栏第一项。依次连续显示美股讯息→具体人物→具体个股→AI板块，四个原页面保留；无额外采集、调度或更新按钮。

## 阅读

- 只显示所选北京时间日期首次收录或有实质进展的信息，不把检查/快照发布时间当新增；同日早晚更新累计，不以最后一批覆盖早报。
- 新闻使用`reading-board`的`firstSeenAt/lastMaterialAt`，更正用其真实检查时间并保留更正依据和此前版本。人物/个股/AI新卡由发布助手维护`firstIncludedAt/lastMaterialAt`，纯排序或互动数变化不刷新实质时间。
- 历史卡没有收录时间时不能补造，按原帖发布日进入对应日期，标为“发布于所选日”。页面不会因迁移而将整份存量冒充今天更新。
- 默认使用四个来源最近成功截止对应的北京时间日期，不跟浏览器跨午夜自动清空。可选择当前缓存中仍有证据的日期；这不是全量历史归档，不承诺已从源数据移出的旧卡仍在这里可读。
- 按栏目→人物/股票/AI子类分组，明确分隔、栏目头吸顶，全文及影响展开。提供本页跳转和原栏目链接。原文、作者、事件时间、知识应用、影响对象与必要更正不删。
- 同栏目、同类型的共同事件正文只展示一次，后续子类链接到上文；不同栏目保留各自分析语境，热点与事实不能互相吞并。
- 个股X热点独立标“非官方”，保持不确定性，不伪装为已证实信息。一个来源失败仅影响该栏目，保留其他可读栏目并显示短异常。

## 发布

与既有静态站一起由Cloudflare构建，不增加依赖或服务器。公共打包仅包含展示脚本、页面和已有公开数据，检索审计/知识库/凭证不进入站点构建。规则与布局基线见[设计系统](DESIGN_SYSTEM.md)，采集执行见[增量采集](INCREMENTAL_COLLECTION.md)。
