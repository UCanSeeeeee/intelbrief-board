- Grok Bot「X+github」：独立启动、采集、筛选、内容质量审查、归档、测试与校验、提交数据、推送、确认线上发布、有限重试及失败报告。

## 原生例行任务

每天北京时间（Asia/Shanghai）09:00、16:00、21:00 **启动美股讯息期次**，不是承诺整点已发布。仅保留一套 Grok Bot 原生调度；若平台需拆为三个任务，三个时刻各一项，不额外启用 Codex、OS cron 或 GitHub Actions 调度。

任务开始先安全同步远端，读取 AGENTS.md、CONTEXT.md、docs/STOCK_BRIEF.md、config/research-guidance.json 及其指向的知识库/SOP。保留未提交改动；冲突不强推。通过 `npm run brief:slot` 确认最近期次；已有归档不覆盖、不重采，未确认部署则仅核验发布。

由 Grok Bot 自己执行两轮独立检索、窗口覆盖与审计、去重和筛选。最多 5 条市场焦点 + 10 条多学科洞察；不足不充数，失败不得冒充无新增。具体质量和时间规则以 STOCK_BRIEF / SOP 为准，不在此复制一套。

由 Grok Bot 调用项目程序验证与归档，运行 `npm test`、`npm run check`、`npm run build`；只提交本任务明确的数据文件和必要审计记录，推送 master。随后核对线上期次及对应数据与提交一致，报告期次、条数、缺口、提交和链接。Git 推送成功不等于网页发布成功。

只在既有 GitHub/Cloudflare 权限内执行。遇到登录、权限、网络、额度或冲突障碍时报告具体原因；不新增密钥、扩大权限、购买额度、关闭安全措施，也不召回 GPT 代执行。代码缺陷交给 GPT 维护。项目仓库知识是已授权执行材料；不读取或发送仓库外个人隐私、凭证、人物原始档案。
