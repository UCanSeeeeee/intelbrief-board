# 设计系统：Linear Calm Density

本文件是 intelbrief-board 所有前台页面（美股讯息、具体人物、具体个股、AI板块、加密、财报日历）的 UI 标准。新增页面或组件必须复用这里的 token 与组件，不另起配色或间距体系。实现在 `styles.css` 的 `:root` token 与末尾「Design system layer」。

## 原则
- **安静**：单一深色主题，低饱和；唯一强调色是蓝色 `--accent-blue`，只用于当前位置（激活导航/Tab）与焦点。状态色（绿/琥珀/红）只表达状态。
- **密集但有层级**：标题 → 正文 → 辅助信息三层灰阶；用间距和细边框分组，不用重阴影和大色块。
- **可读的中文**：系统字体栈（含 PingFang SC / 微软雅黑 / Noto Sans CJK），正文行高 1.7，段落最大行宽 72ch，数字等宽（tnum）。

## Token
| 类别 | Token |
|---|---|
| 背景 | `--bg #0a0a0b` / `--bg-elevated #111113` / `--bg-card #151518` / `--bg-hover #1c1c1f` |
| 边框 | `--border #27272a`、`--border-subtle #1f1f23`，统一 1px |
| 文字 | `--text #fafafa`（≈19:1）、`--text-secondary #b4b4bd`（≈10:1）、`--text-muted #8e8e98`（≈6:1），均满足正文 ≥4.5:1 |
| 强调/焦点 | `--accent-blue #7c9cff`、`--focus #8ab4ff` |
| 字号 | 12 / 13 / 15（正文）/ 17 / 22 / 28 |
| 间距（4/8 网格） | 4 · 8 · 12 · 16 · 24 · 32 · 48（`--sp-1`…`--sp-7`） |
| 圆角 | 6（控件）/ 8（Tab）/ 12（卡片）/ 999（徽章） |
| 阴影 | 仅 `--shadow-1`（1px 内高光 + 微投影） |

## 组件
- **侧栏导航**：固定顺序 美股讯息 → 具体人物 → 具体个股 → AI板块 → 加密 → 财报日历；当前项 `aria-current="page"`、左侧 2px 蓝条、加粗。≤768px 变为抽屉，44px 菜单按钮，Esc 关闭，`aria-expanded` 同步。
- **顶部 Tab**：`role="tablist"` / `role="tab"` + `aria-selected`；←/→/Home/End 切换（`app.js` 统一处理）；选中态为蓝色描边 + 底部 2px 指示。
- **卡片**：12px 圆角、1px 边框、24px 内边距（移动端 16px）；作者 → 标题 → 标签行 → 正文 → 反向条件 → 时间与原文链接。
- **徽章 / 层级**：胶囊描边，12px；不以颜色作为唯一信息载体。
- **财报卡**：代码（17px 粗）→ 时段/主题徽章 → 公司名 → 主营一句话（左侧细线）→ 市值/EPS → 结果（底部分隔）。
- **空态 / 错误**：虚线框 + 一句粗体结论 + 一句说明，不用旧数据凑数。
- **列表 / 表格**：行间用 `--border-subtle` 分隔，数字右对齐等宽。

## 无障碍（WCAG 2.2 AA 基线）
- 正文对比 ≥4.5:1；所有可交互元素有可见 `:focus-visible` 轮廓（2px `--focus`）。
- 移动端触控目标 ≥44×44px。
- 每页一个 `h1`，分区用 `h2`；地标：`aside`（站点导航）、`nav`（主导航）、`main#main`；首个可聚焦元素是「跳到正文」。
- 装饰性图标 `aria-hidden`；按钮有中文 `aria-label`。
- 尊重 `prefers-reduced-motion`；`forced-colors` 下保留当前位置轮廓。
- 主题：只维护深色主题（主题），暂不做浅色，避免两套未校验的对比度。
