# 设计系统：阅读优先的美股情报台

本文件是 intelbrief-board 所有前台页面（美股讯息、具体人物、具体个股、AI板块、每日学习、宏观大事、财报日历）的UI标准。用户已认可首页阅读优先的方向，并授权推广全站。加密与板块空头保持停用。styles.css保留基础Token与骨架，reading.css统一阅读组件，news.css只维护新闻首页特例；首页加载styles → reading → news，其他页面加载styles → reading。不另起配色、字体或技术栈。

## 原则
- **阅读优先，删除说明性UI**：正文、影响判断、实验过程、必要结论边界和实质更正默认完整显示，仍使用的`details`带`open`。不展示筛选/补位规则、采集调度、数量/上限、检索审计、方法论免责声明、栏目宣传、副标题或侧栏标语，不把它们改成折叠入口。规则和原始记录保留在配置/文档/JSON，不降低证据标准。
- **安静**：单一深色主题，低饱和；蓝色`--accent-blue`用于当前位置、焦点与原文入口。状态色（绿／琥珀／红）只表达真实状态。
- **密集但有层级**：标题 → 正文 → 辅助信息三层灰阶；用间距和细边框分组，不用重阴影和大色块。
- **可读的中文**：系统字体栈（含PingFang SC／微软雅黑／Noto Sans CJK），正文行高1.7–1.8，宽屏用阅读分栏限制行长，手机单栏；数字等宽tnum，不以截字限制长度。

## 组件
- **侧栏导航**：固定顺序 美股讯息 → 具体人物 → 具体个股 → AI板块 → 每日学习 → 宏观大事 → 财报日历；当前项 `aria-current="page"`、左侧 2px 蓝条、加粗。≤768px 变为抽屉，44px 菜单按钮，Esc 关闭，`aria-expanded` 同步。
- **页头**：只保留标题、导航和一处低强调的真实截止；不堆徽章、口号、总数或重复说明，不提供采集按钮。
- **情绪与波动卡**：CNN情绪与VIX并排，手机上下排；保留数值、状态、真实日期和来源链接。正常状态不加解释徽章，仅过期/失败提示。VIX按用户四档，不附历史恐慌案例或交易建议。见[情绪](MARKET_SENTIMENT.md)及[VIX](MARKET_VOLATILITY.md)。
- **顶部 Tab**：文字与底线选中状态，触控目标至少44×44px，不套一排大卡片。保留`role="tablist"`／`role="tab"`、aria-selected与键盘切换；页面已处理的键盘事件不由app.js重复处理。名称完整、个股用代码，按宽度换行，不重复窗口规则。
- **卡片**：8px圆角、1px轻边框，横向24px内距（手机16px）；作者／发布／核验低强调，标题后直接进入摘要与影响，宽屏并列、≤1120px窄桌面和手机上下排列。正文、人物简介、事件时间、知识应用与原文入口完整保留；不截字、不展示反向条件。来源身份与主张核验分开：Grok转述显示待独立核验。
- **状态／层级**：热度、评级和新增／延续身份用12px轻量文字，不堆重复胶囊，不以颜色作为唯一信息载体。真实异常与实质更正不隐藏。
- **日历**：通栏日程行、周/季度Tab、日期与星期清晰可见；保留业务简介、结果与依据，不展示收录规则、入选/原始数量或名额上限排除列表。
- **空态 / 错误**：虚线框 + 一句粗体结论 + 一句说明，不用旧数据凑数。
- **列表 / 表格**：行间用 `--border-subtle` 分隔，数字右对齐等宽。

## 无障碍（WCAG 2.2 AA 基线）
- 正文对比 ≥4.5:1；所有可交互元素有可见 `:focus-visible` 轮廓（2px `--focus`）。
- 移动端触控目标 ≥44×44px。
- 每页一个 `h1`，分区用 `h2`；地标：`aside`（站点导航）、`nav`（主导航）、`main#main`；首个可聚焦元素是「跳到正文」。
- 装饰性图标 `aria-hidden`；按钮有中文 `aria-label`。
- 尊重 `prefers-reduced-motion`；`forced-colors` 下保留当前位置轮廓。
- 主题：只维护深色主题（主题），暂不做浅色，避免两套未校验的对比度。

## 禁止截断（硬规则）
展示文字均不截断：禁止ellipsis、line-clamp、固定高度裁切及JS截字；长词与URL自然换行。正文和影响判断完整显示；说明性UI直接移除，不用截字或折叠代替清理。条目上限属于内部内容规则，不必展示。`test/no-truncation.test.js`维护此约束。

## 阅读语义与时间

- 同Tab的独立板块用明确标题、组间留白和细分隔线区分，不套整条大色条。全站默认展开，不靠折叠或截字制造层次。
- 财报与宏观的日期分组头吸顶，日期和星期清晰，下一组自然接替；财报保留美东披露日期，手机给菜单留出空间，不将Nasdaq日期误标为北京时间。公司／事件仍为通栏行，宽屏行内将业务／事件与结果／时间并列，窄桌面和手机上下排列。
- 网页只负责展示，不提供“更新”按钮、登录、任务进度、重试或手动触发对话框。

- 美股讯息默认“当前重点”，保留5+10精选及溢出有效卡片，可切回三期快照；保留必要新增/进展身份和实质更正，不展示生命周期操作记录。见[增量采集](INCREMENTAL_COLLECTION.md)。
- 人物/个股/AI按最近成功数据截止过滤阅读窗口，不随浏览器时钟自行清空；被近窗名额挤出的有效规则卡放累计保留区，不拿旧卡冒充新增。
- 不展示收录数量、名额上限、Tab总数或完成率；真实失败/过期用短提示，不把失败改成“暂无新增”。归档和检索范围不变。
- 宏观按美东日期分组，使用事件的真实美东时刻与 `America/New_York` 夏令时规则换算北京时间；没有具体时刻就明确待确认，不凭日期补一个北京时间。
- 财报尚未到披露日显示「待披露」；过了预定时段不等于已经披露，显示「披露状态待核验」。有披露证据才显示「结果待补录」或「待评分」，缺失分数不能显示为 0 分。逻辑统一维护在 `calendar-time.js`。
- 页标题少量采用 Microsoft Fluent Emoji 3D 装饰素材，空替代文字，不在卡片堆叠表情。来源、固定版本与 MIT 许可见 `assets/fluent/README.md`。
- 每日学习的基础知识卡同时展示专业版与故事版：桌面双栏、手机单栏。两版共用同一知识点对象；故事版必须标注角色对应关系和类比边界，不得产生专业版没有的新事实。
- 本轮不引入收藏、已读或搜索系统，不更改既有情报数据筛选规则。

## 全站阅读布局

七个活跃页面均加载reading.css；仅首页另加载news.css维护指标区、期次和简报特例。共用组件在reading.css维护，不为各Tab复制一套设计体系。

- 采用design-taste-frontend的应用界面思路，延用已认可的Data terminal方向（seed 1184106250）；保留中文系统字体、深色和七项文字侧栏，不套图标侧栏，不增加动效或依赖。营销页面规则不适用于本产品，技能不覆盖用户的完整展示与来源规则。
- 页头合并标题、真实截止和期次选择；CNN／VIX保留完整数据、四档、来源和日期，只缩短布局高度。指标是市场背景，新闻是首屏主体。
- 新闻、人物、个股和AI的作者、发布时间、核验及新增／延续状态组成低强调元信息；标题后直接是摘要与影响，宽屏并列、窄屏上下排列，内容完整展开。保留原窗口、排序、Tab选择和键盘行为。
- 影响范围、方向和窗口改成卡片尾部的简洁文字，不删除原有信息。相关人物、事件时间、知识应用、原文链接和更正时间线全部保留。
- 学习的专业版与故事版同卡并列，手机单栏；保留故事标题、角色映射、类比边界和误区。论文先结论，实验过程与实验结果宽屏并列，结论边界单独成行，手机按结论→过程→结果→边界阅读。反直觉小知识保留直觉、证据、解释与边界，来源日期在卡片尾部。
- 板块以明确标题、留白和细线区分，不再套整条蓝色底板。卡片使用统一轻边界，不增加阴影、渐变、重复胶囊或假数据。
- 设计维护不刷新新闻、不改期次保留、采集或接口。按项目约定不运行本地test/check/build/预览；发布后核对Cloudflare和线上实际页面，没有执行的多视口、对比度或交互检查不能宣称通过。

## 进页默认行为（2026-10-15）

- 具体人物：每次进入页面默认选中配置的第一个 Tab（马斯克）；会话内可切换，刷新/再进仍回第一个。
- 宏观大事：进入当前季度后自动滚到北京时间当日（或最近有事件的日期）分区。
