# 设计系统：Linear Calm Density

本文件是 intelbrief-board 所有前台页面（美股讯息、具体人物、具体个股、AI板块、每日学习、宏观大事、财报日历）的 UI 标准。加密栏目已于2026-10-15暂时停用。新增页面或组件必须复用这里的 token 与组件，不另起配色或间距体系。2026-10-12 采用阅读优先调整，实现在 `styles.css` 末尾「Reading-first refinement」。

## 原则
- **默认展开（2026-10-12用户新要求）**：所有阅读内容默认完整显示，包括影响分析、关注规则、公司介绍、检索/复核记录、评分说明及其余有效待阅条目；`details` 必须带 `open`，用户仍可主动收起。所有情报卡片移除“反向条件”展示；历史JSON和内部反证核验保留，不删历史、不改变采集证据契约。此规则覆盖旧版默认收起的设计。
- **安静**：单一深色主题，低饱和；唯一强调色是蓝色 `--accent-blue`，只用于当前位置（激活导航/Tab）与焦点。状态色（绿/琥珀/红）只表达状态。
- **密集但有层级**：标题 → 正文 → 辅助信息三层灰阶；用间距和细边框分组，不用重阴影和大色块。
- **可读的中文**：系统字体栈（含 PingFang SC / 微软雅黑 / Noto Sans CJK），正文行高 1.7，段落最大行宽 72ch，数字等宽（tnum）。

## Token
| 类别 | Token |

## 组件
- **侧栏导航**：固定顺序 美股讯息 → 具体人物 → 具体个股 → AI板块 → 每日学习 → 宏观大事 → 财报日历；当前项 `aria-current="page"`、左侧 2px 蓝条、加粗。≤768px 变为抽屉，44px 菜单按钮，Esc 关闭，`aria-expanded` 同步。
- **页头**：显示标题、必要副标题与真实的数据截止；不提供采集按钮或手动更新入口，来源标签不使用绿色成功点。
- **美股情绪卡**：页头下、期次选择前展示CNN恐惧与贪婪指数；大数字、文字情绪、低饱和色带及历史对比，手机自然换行。独立显示时间、镜像及过期/失败提示，不单靠颜色表达状态，不加更新按钮。见[指标说明](MARKET_SENTIMENT.md)。
- **顶部 Tab**：`role="tablist"` / `role="tab"` + `aria-selected`；←/→/Home/End 切换；页面已处理的键盘事件不再由 `app.js` 重复处理。仅显示简洁完整的名称（个股用代码），按宽度换行，不在每个按钮重复窗口规则。
- **卡片**：12px 圆角、1px 边框、横向 24px 内边距（移动端 16px）；标题、作者、核验状态、摘要、时间、原帖入口直接可见。影响判断默认完整展开，不截字、不展示反向条件。来源身份与主张核验分开：Grok 转述显示「待独立核验」。
- **徽章 / 层级**：胶囊描边，12px；不以颜色作为唯一信息载体。
- **日历**：宏观、财报使用通栏日程行；顶部Tab只放季度/周名称，范围移到Tab下方。公司介绍、收录说明、结果与依据默认展开，用户可主动收起；无事件日期紧凑展示。
- **空态 / 错误**：虚线框 + 一句粗体结论 + 一句说明，不用旧数据凑数。
- **列表 / 表格**：行间用 `--border-subtle` 分隔，数字右对齐等宽。

## 无障碍（WCAG 2.2 AA 基线）
- 正文对比 ≥4.5:1；所有可交互元素有可见 `:focus-visible` 轮廓（2px `--focus`）。
- 移动端触控目标 ≥44×44px。
- 每页一个 `h1`，分区用 `h2`；地标：`aside`（站点导航）、`nav`（主导航）、`main#main`；首个可聚焦元素是「跳到正文」。
- 装饰性图标 `aria-hidden`；按钮有中文 `aria-label`。
- 尊重 `prefers-reduced-motion`；`forced-colors` 下保留当前位置轮廓。
- 主题：只维护深色主题（主题），暂不做浅色，避免两套未校验的对比度。

## 禁止截断（硬规则）
任何展示文字均不截断：禁止 `text-overflow: ellipsis`、`line-clamp` / `-webkit-box` 截行、`overflow: hidden` 裁切文字、固定高度裁切内容、`white-space: nowrap` 导致溢出，以及 JS 用 `.slice/.substring/.substr` 截断展示文本或手工加「…」。长词与 URL 用 `overflow-wrap: anywhere` 换行。标题和信息摘要始终完整可见；影响分析、关注规则和公司背景默认呈现全文，可由用户主动收起。条目数量上限（如近窗 ≤5）是内容规则，不属于文字截断。`test/no-truncation.test.js` 强制执行。

## 阅读语义与时间

- 2026-10-12：同tab的独立内容板块使用2px顶边、带底色标题条、左侧强调线与32–40px间距；卡片边框只负责板块内部。全站内容仍默认展开，不靠折叠制造层次。
- 财报每个日期分组标题吸顶，显示日期、星期及“美东披露日期”，下个日期自然接替；手机预留左侧菜单空间，不将Nasdaq日期误标成北京时间。组内公司依旧通栏。
- 网页只负责展示，不提供“更新”按钮、登录、任务进度、重试或手动触发对话框。

- 美股讯息默认“当前重点（累计保留）”，精选最多5+10，溢出有效卡片默认展开；可切回三期快照。标记本轮新增/有进展/累计保留；同事件一张当前卡，历史版本及更正依据默认展开。08:00重点到20:00仍可读，已展示不等于已读。见[增量采集](INCREMENTAL_COLLECTION.md)。
- 人物/个股/AI按最近成功数据截止过滤阅读窗口，不随浏览器时钟自行清空；被近窗名额挤出的有效规则卡放累计保留区，不拿旧卡冒充新增。
- 数量显示「收录 N 条 · 上限 M 条」，不是完成率；不足不补新闻。期次仍保留真实的缺额、失败状态，不把采集失败美化成精选。归档数据与检索范围不因改版改变。
- 宏观按美东日期分组，使用事件的真实美东时刻与 `America/New_York` 夏令时规则换算北京时间；没有具体时刻就明确待确认，不凭日期补一个北京时间。
- 财报尚未到披露日显示「待披露」；过了预定时段不等于已经披露，显示「披露状态待核验」。有披露证据才显示「结果待补录」或「待评分」，缺失分数不能显示为 0 分。逻辑统一维护在 `calendar-time.js`。
- 页标题少量采用 Microsoft Fluent Emoji 3D 装饰素材，空替代文字，不在卡片堆叠表情。来源、固定版本与 MIT 许可见 `assets/fluent/README.md`。
- 每日学习的基础知识卡同时展示专业版与故事版：桌面双栏、手机单栏。两版共用同一知识点对象；故事版必须标注角色对应关系和类比边界，不得产生专业版没有的新事实。
- 本轮不引入收藏、已读或搜索系统，不更改既有情报数据筛选规则。

## 进页默认行为（2026-10-15）

- 具体人物：每次进入页面默认选中配置的第一个 Tab（马斯克）；会话内可切换，刷新/再进仍回第一个。
- 宏观大事：进入当前季度后自动滚到北京时间当日（或最近有事件的日期）分区。
